# ✈️ Al-Riyadah International Airport - Web App

An interactive front-end web application for a modern international airport. This project provides a responsive user interface that allows travelers to explore flight schedules, airport services, and manage their flight bookings completely client-side.

##  Key Features
* **Flight Booking System:** Interactive booking form with strict input validation to prevent empty submissions.
* **Local Data Storage:** Bookings are saved, edited, retrieved, and deleted locally using the browser's `localStorage` (No backend database required).
* **Responsive Design:** Fully optimized for both desktop and mobile devices using CSS Flexbox, Grid, and Media Queries.
* **Interactive UI:** Features a dynamic welcome screen, tabbed navigation for flight statuses, and task controls integrated into the bookings table.

##  Demo Credentials
To test the application and its features, please use the following credentials:
* **Initial Login Page:** Password is `1234` (You can enter any username).
* **Admin Controls (Edit/Delete Bookings):** Username `admin` / Password `admin`.

##  Technologies Used
* **HTML5:** Semantic page structure.
* **CSS3:** Styling and responsive layout architectures.
* **JavaScript (Vanilla):** DOM manipulation, event handling, and localStorage integration.

## 📂 Project Structure & Pages
1. **Login Page (`login.html`):** Initial screen to verify the user and save the username to local storage.
2. **Home Page (`project.html`):** Main dashboard featuring destination cards, airport services grid, and a tabbed table for arriving/departing flights.
3. **Booking Page (`book.html`):** The core reservation system featuring a data collection form and a dynamic table to display, edit, and delete bookings.
4. **About Page (`about.html`):** Information about the airport's vision, objectives, and features.

# ✈️ مطار الريادة الدولي - تطبيق ويب

تطبيق ويب تفاعلي يخدم مطاراً دولياً حديثاً. يوفر هذا المشروع واجهة مستخدم متجاوبة تتيح للمسافرين استعراض جداول الرحلات وخدمات المطار، بالإضافة إلى إدارة حجوزات الطيران بالكامل من خلال المتصفح.

##  المميزات الرئيسية
* **نظام حجز الرحلات:** نموذج حجز تفاعلي مزود بنظام التحقق من صحة المدخلات (Validation) لمنع إرسال بيانات فارغة.
* **إدارة التخزين المحلي:** يتم حفظ، استرجاع، تعديل، وحذف الحجوزات محلياً باستخدام `localStorage` في المتصفح (لا يحتاج إلى قاعدة بيانات خلفية).
* **تصميم متجاوب (Responsive):** يعمل بكفاءة عالية على شاشات الكمبيوتر والجوال باستخدام أنظمة (Flexbox و Grid) والـ Media Queries.
* **واجهة تفاعلية:** يحتوي على شاشة ترحيبية ديناميكية، ونظام تبويبات (Tabs) لعرض حالة الرحلات، وأدوات تحكم مدمجة في جدول الحجوزات.

## بيانات الدخول التجريبية

* **صلاحيات المدير (للتعديل والحذف):** اسم المستخدم `admin` / كلمة المرور `admin`.

## التقنيات المستخدمة
* **HTML5:** لبناء الهيكل الأساسي (Semantic Structure) وتنظيم المحتوى.
* **CSS3:** لتنسيق واجهة المستخدم وتطبيق أنظمة التخطيط الحديثة.
* **JavaScript:** لإضافة التفاعل (DOM Manipulation)، معالجة الأحداث، وإدارة البيانات في الذاكرة المحلية (localStorage).

## 📂 صفحات المشروع
1. **صفحة تسجيل الدخول (`login.html`):** صفحة مبدئية تطلب من المستخدم إدخال اسمه للتحقق وحفظه في الذاكرة.
2. **الصفحة الرئيسية (`project.html`):** الشاشة الأساسية؛ تحتوي على كروت الوجهات، شبكة الخدمات، وجدول حالة الرحلات القادمة والمغادرة.
3. **صفحة الحجز (`book.html`):** تقوم بعملية الحجز وتحتوي على نموذج لجمع البيانات، وجدول يعرض الحجوزات مع أزرار التحكم (حذف/تعديل).
4. **صفحة عن المطار (`about.html`):** صفحة تعريفية تحتوي على معلومات تفصيلية عن المطار ومميزاته.
